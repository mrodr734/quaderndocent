🔑 Com aconseguir la clau API de Gemini?

Segueix aquests passos senzills per obtenir la teva clau de Google:

  1. Accedeix a Google AI Studio.
  2. Identifica't amb el teu usuari d'XTEC.
  3. Al menú lateral, ves a Dashboard.
  4. Entra a Claus API (o API Keys).
  5. Genera una clau nova (Create API Key) i copia-la.
💡 Un cop la tinguis copiada, enganxa-la a la casella superior i prem "Desar clau".
⚠️ Atenció: Si esgotes el límit de l'API, utilitza el Generador de Prompt.

🔒 Avís de privacitat i bones pràctiques

1. Ús del compte educatiu XTEC:
Es recomana utilitzar aquesta eina identificat/ada amb el teu compte institucional XTEC. Els entorns educatius corporatius de Google disposen de garanties addicionals de protecció de dades i privacitat contractuals ajustades al RGPD per als centres docents.
2. Emmagatzematge local (100% privat):
Totes les notes, observacions, tasques i dades dels alumnes s'emmagatzemen exclusivament al teu navegador web (`localStorage`). No es guarda res en cap servidor extern ni base de dades al núvol. Per això, és fonamental realitzar còpies de seguretat periòdicament des del botó "💾 Exportar còpia".
3. Recomanació d'anonimització:
Per garantir una protecció total de la identitat de l'alumnat:
  • És preferible registrar els infants utilitzant només el nom de pila o la inicial del primer cognom en lloc del nom complet.
  • En generar informes amb IA, les anotacions marcades com a 🔒 internes mai s'enviaran a l'API.
4. Llicència i comunitat:
Projecte de codi obert allotjat a GitHub sota llicència MIT.
