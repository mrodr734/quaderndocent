🔑 Com aconseguir la clau API de Gemini?

Segueix aquests passos senzills per obtenir la teva clau gratuïta de Google:

  1. Accedeix a Google AI Studio.
  2. Identifica't amb el teu usuari d'XTEC.
  3. Al menú lateral, ves a Dashboard.
  4. Entra a Claus API (o API Keys).
  5. Genera una clau nova (Create API Key) i copia-la.
💡 Un cop la tinguis copiada, enganxa-la a la casella superior i prem "Desar clau". Quedarà desada al teu navegador.

🔒 Avís de privacitat i seguretat de les dades

1. Ús del compte educatiu XTEC:
Es recomana utilitzar aquesta eina identificat/ada amb el teu compte institutional XTEC. Els entorns educatius corporatius de Google disposen de garanties addicionals de protecció de dades i privacitat contractuals ajustades al Reglament General de Protecció de Dades (RGPD) per als centres docents.
2. Emmagatzematge local (100% privat):
Totes les notes, observacions, tasques i dades dels alumnes s'emmagatzemen exclusivament al teu navegador web (`localStorage`). No es guarda res en cap servidor extern ni base de dades al núvol. Per això, és fonamental realitzar còpies de seguretat periòdiques des del botó "💾 Exportar còpia".
3. Recomanació d'anonimització:
Per garantir una protecció total de la identitat de l'alumnat:
  • És preferible registrar els infants utilitzant només el nom de pila o el nom amb la inicial del primer cognom (p. ex. "Marc P." o "Laia") en lloc del nom i dos cognoms complets.
  • En generar informes amb IA, la informació s'envia processada de forma anònima i les anotacions marcades com a 🔒 internes mai s'enviaran a l'API.
