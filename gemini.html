🤖 Generador de Prompt per a la web de Gemini

Generador d'informes alternatiu per quan s'ha esgotat la quota diària de la clau API de Google.

💡 Com funciona aquesta alternativa? Carrega la còpia de seguretat JSON del teu Quadern Docent, tria l'alumne/a i es generarà un prompt especialment redactat amb el rol de mestre/a d'educació primària. Només l'hauràs de copiar i enganxar al xat gratuït de Gemini Web juntament amb el teu fitxer.

📋 Passos per generar l'informe manualment

1 Carrega el teu fitxer JSON de seguretat

Selecciona el fitxer .json que vas exportar des de la teva aplicació principal amb el botó "💾 Exportar còpia".

2 Selecciona el grup, l'alumne/a i el tipus d'informe
3 Copia el prompt resultant
El prompt apareixerà aquí un cop seleccionis un alumne/a...
4 Executa-ho a Gemini Web
  1. Entra a gemini.google.com.
  2. Adjunta el mateix fitxer .json fent clic a la icona del clip 📎 o d'afegir fitxers.
  3. Enganxa el prompt que acabes de copiar al quadre de text i prem **Enviar**.
