Obtenir la clau API de Gemini amb l'XTEC

L'aplicació utilitza la clau d'API de Google Gemini per processar la informació de les Situacions d'Aprenentatge.

  1. Entra a Google AI Studio amb el teu compte de l'XTEC.
  2. Clica a "Create API key".
  3. Copia la clau generada, engalta-la al camp superior de l'aplicació i prem Desar.
